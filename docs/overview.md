# Overview

Flow Engine parses source code, builds a dependency graph, and derives deterministic reports from that graph.

Core outputs include:

- Nodes and edges
- Coupling metrics
- Hotspots
- Dependency cycles
- Architecture violations
- Orphan candidates
- Bug patterns
- Change impact
- Risk score
- AI-ready context

The same engine powers the CLI, MCP server, local read-only API, Docker workflow, and exports.
